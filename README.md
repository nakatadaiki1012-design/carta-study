# 🎴 百人一首 道場（練習アプリ）

本物のかるたで練習しているような**リアルな札**と、**音声の読み上げ**で百人一首を練習できるWebアプリです。
`index.html` をブラウザ（スマホ・タブレット・PC）で開くだけで使えます。インストール不要。

**GitHub Pages で公開すると便利です**：リポジトリの Settings → Pages → Branch を `main` にして保存すると、
`https://<ユーザー名>.github.io/carta-study/` で開けます。スマホではブラウザのメニューから「ホーム画面に追加」すると
アプリのように起動でき、⚙ 設定の「読み上げ音声をすべて保存」で電波がなくても使えます。

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `data.js` | 百人一首100首のデータ（漢字・歴史的かなづかい・読み上げ用のかな） |
| `portrait.js` | 読み札の歌仙絵（歌人の姿）を描くプログラム |
| `audio/` | 読手風の読み上げ音声（上の句・下の句・序歌）と、一音ずつの時刻 `timing.js` |
| `tools/make_audio.py` | 読み上げ音声を作り直すためのプログラム |
| `manifest.webmanifest` / `sw.js` / `icons/` | ホーム画面への追加・オフライン利用のための設定とアイコン |

## 3つのレベル

### 🟢 初心者「覚える」
- **暗記カード**：読み札（上の句）を音声で聞き、取り札をめくって下の句を確認。「○覚えた／×まだ」で記録されます。
- **4択で取る**：上の句を聞いて、4枚の取り札から正しい札を選ぶクイズ（10問）。「似た札をまぜる」で難しくできます。
- **声で答える**：上の句を聞いたら、下の句を**声に出して**答える。マイクで聞き取って自動で判定します（Chrome・Safari・Edge）。
- **一覧**：100首を一覧表示。決まり字が赤字で分かります。
- **連続再生（聞き流し）**：上の句 → 札をめくる → 下の句 → 次の歌、を自動でくり返します。

### 🟡 中級者「取る」
- 畳の上に取り札（8〜25枚）を並べ、読み上げを聞いて正しい札をタップ。
- 札は競技かるたと同じく**下段・中段・上段の3段**に、左右に分けて並びます。
- 違う札にさわると**お手つき**。「空札あり」にすると、場にない歌も読まれます（本番と同じ）。
- 読んでいる文字を画面に出す／出さないを選べます。

### 🔴 上級者「早く取る」
- 25枚または50枚。**相手陣は逆さ**に向かい合わせで並ぶ本番形式。序歌（なにわづに…）から始まります。
- **暗記時間**（30秒〜15分）で札の位置を覚えてから始められます。
- **定位置風の並べ方**：決まり字の短い札ほど手前（下段）に、同じ頭の札（友札）は同じ側にまとめます。
- **本番の読み方**：前の歌の下の句をもう一度読み、余韻と一拍の間をおいてから次の上の句へ進みます。
- お手つきは競技のルールどおり：正しい札と**同じ陣の札にさわってもセーフ**、ちがう陣の札・空札のときはお手つき。
- **対戦ルール**：相手陣の札を取ったら自陣の札を1枚送る（送り札）。自陣の札を相手に取られたり、お手つきをしたりすると相手から1枚送られてきます。**先に自陣の札をなくしたら勝ち**。
- **相手の強さ**：初心者（決まり字から約1.6秒）〜名人（約0.32秒）。決まり字が読まれてからその時間が過ぎると、仮想の相手が札を取ります。
- **決まり字の練習**：決まり字まで読んだところで読み上げを止め、短く聞いて取る練習ができます。
- 取った時間に加えて、**決まり字が読まれてから何秒で取れたか**を記録。目標は「決まり字を聞いた瞬間」。
- 読まれた歌が増えると決まり字が短くなる**決まり字の変化**にも対応（ヒント表示で確認できます）。
- 平均時間の**自己ベスト**を保存。

### 📈 苦手な歌の記録
- 取れなかった歌・お手つきした歌を記録します。結果画面の「復習したい歌」から暗記カードへ。
- ⚙ 設定の範囲「苦手な歌」で、苦手な歌だけをまとめて練習できます。

## 読み上げの声
- **読手風の音声**（おすすめ）：かるたの読手のように、一音ずつ同じ長さで、高さをほぼ一定にして、句の終わりを長くのばして読みます。どの端末でも同じ声・同じ読み方になります。
- 文字の表示や「決まり字が読まれた瞬間」は、音声の一音ずつの時刻にぴったり合わせています。
- 設定で「この端末の音声」「音声なし」にも切りかえられます。
- 音声は音声合成エンジン Open JTalk と音声「メイ」（名古屋工業大学, CC BY 3.0）で作り、`tools/make_audio.py` で読手風に加工しています（音量は聞こえる大きさでそろえています）。

## 本物らしさのこだわり
- 取り札は**ひらがなの下の句だけ**を縦書き3列、緑のふち付き。設定で「本物風（濁点なし・『ゝ』を使う）」と「わかりやすく（濁点あり）」を切り替えられます。
- 読み札は漢字の歌と作者名に加え、**歌仙絵**（歌人の姿）入り。天皇は御簾と繧繝縁の畳、女性は十二単の重ね色、僧は袈裟など、身分ごとに描き分けています。
- 「覚える」の暗記カードでは、読み札の**下の句は伏せて**あり、取り札をめくると出てきます。
- 書体は明朝／毛筆風を選べます。

## 設定（⚙）
- 練習する範囲：全100首／20首ずつ／1字決まり・2字決まり…／まだ覚えていない歌／苦手な歌
- 音声のオン・オフ、声の種類、読む速さ（ゆっくり・ふつう・試合くらい）

## キーボード（PC）
- 対戦中：スペース／Enter＝次へ
- 暗記カード：スペース＝めくる、← →＝前後、O＝覚えた、X＝まだ

## 注意
- iPhoneは消音スイッチをオフにしてください。
- 「この端末の音声」を選んだときは、端末によって声や読み方が違い、文字と声のタイミングは目安になります。
- 覚えた記録・設定は、その端末のブラウザに保存されます。
